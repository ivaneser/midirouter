# Как сделаны рецепты FM-пресетов и как выбирать алгоритм и параметры

Файл описывает семь пресетов из `fm-recipes.json` (EPiano, Bell, Bass, Organ, StrPad, Glass, Pluck) и общий порядок, по которому звук собирается с нуля на PreenFM2. Порядок можно применять к любому новому звуку.

## 1. Как создавались рецепты

1. **Исходная точка — теория FM, а не копирование готовых патчей.** Для каждого звука я взял известные правила FM-синтеза (соотношения частот, смысл индекса модуляции, роль огибающих) и перевёл их в значения параметров PreenFM2.
2. **Звук собирался «с нуля».** В `fm-recipes.json` лежит только то, что отличается от начального патча. Остальные параметры при загрузке берутся из «Init» (`set_nrpn_parameters` с `from_init: true`). Поэтому рецепт короткий и ничего не наследует от того, что играло раньше.
3. **Значения проверены на формат, а не на слух.** Все имена и диапазоны прошли разбор роутера (синтезатор принял каждый параметр). Затем рецепты по одному загружались в рабочий буфер Part 1, Сергей слушал их и сохранял в свои слоты «Init». Систематической настройки на слух не было, кроме правок, которые он просил. Поэтому числа — хорошая отправная точка, а не окончательные.
4. **Нумерация.** В `values` параметр `Algorithm` считается с нуля (в интерфейсе алгоритмы 1–28). Операторы нумеруются 1–6. `IM n` — индекс модуляции с номером n (это не всегда оператор n). `Mix n` — уровень n-й несущей, а не оператора n.

## 2. Порядок выбора: от желаемого звука к патчу

### Шаг 1. Определить тип спектра

| Хочу | Спектр | Соотношение частот (ratio) |
| --- | --- | --- |
| Тёплый, «музыкальный» тон (бас, клавиши, пад) | гармонический | целые: 1, 2, 3, 4 |
| Колокол, стекло, металл, перкуссия | негармонический | дробные: 3.5, 7.13, 1.41, 2.76 |
| Лёгкая «живость» и хор | почти гармонический | 1 и 1.01 (небольшая расстройка) |
| Орган | чистые гармоники без модуляции | несущие 1, 2, 4 |

Простое правило: целое отношение модулятора к несущей даёт обертоны на гармониках, нецелое даёт звенящие, «неточные по высоте» обертоны.

### Шаг 2. Выбрать алгоритм по числу нужных несущих и цепочек

Несущая — оператор, который слышно напрямую. Модулятор слышно только через то, как он меняет другой оператор.

| Нужно | Алгоритм (схема из карты устройства) | Использован в |
| --- | --- | --- |
| Простая пара «модулятор → несущая» | 1: одна несущая (1), модуляторы 2 и 3 (IM 1: 2→1, IM 2: 3→1, IM 3: 3→2). Для пары оставляют только IM 1, остальные ставят в 0 | Bell, Bass, Glass, Pluck |
| Две несущие, которые питает один общий модулятор | 2: несущие 1 и 2, модулятор 3 (IM 1: 3→1, IM 2: 3→2) | StrPad |
| Две несущие, у каждой свой модулятор | 4: несущие 1 и 2, модуляторы 3 и 4 (IM 1: 3→1, IM 2: 4→2). IM 3 (3→2) и IM 4 (4→3) в рецепте равны 0, поэтому пары независимы | EPiano |
| Несколько несущих без модуляции (орган, аддитивный звук) | 6: несущие 1, 2, 3, их модулятор 4 (IM 1–3) выключен нулевыми индексами | Organ |

Когда выбираете сами, ориентируйтесь на картинку алгоритма в интерфейсе: группы Modulators и Carriers заполняются автоматически, а лишние операторы серые. Чем больше несущих, тем «шире» и «плотнее» звук, чем длиннее цепочка модуляторов, тем он «грязнее» и ярче. Для первого звука берите короткие цепочки.

### Шаг 3. Установить индекс модуляции (IM) — это яркость

| IM | Звук |
| --- | --- |
| 0 | чистая синусоида (или орган, если несущих несколько) |
| 0.5–1.5 | мягкий, тёплый, лёгкий блеск (пад, стекло) |
| 2–3.5 | заметно яркий (электропиано, щипок, бас) |
| 4 и больше | резкий, «пилообразный», металлический |

IM, который не используется выбранным алгоритмом, ничего не делает (ручка серая).

### Шаг 4. Задать огибающие — это форма звука во времени

Главное правило: **огибающая несущей задаёт громкость, огибающая модулятора задаёт тембр.** Яркость, которая гаснет быстрее громкости, делает звук «живым», как у настоящего инструмента.

| Звук | Несущая | Модулятор |
| --- | --- | --- |
| Щипок, бас | быстрая атака, средний спад, без долгого sustain | очень короткая яркость (спад 0.2–0.3), ноль в sustain |
| Колокол, стекло | долгий спад (2.5–3), длинный release (1.5) | короче несущей: удар и быстрое затухание яркости |
| Электропиано | спад 1.5, sustain 0 | вторая пара гаснет быстро, это «язычок» |
| Пад (струнные) | медленная атака (≈0.9), длинный release (≈1.2) | ещё медленнее, чтобы звук «расцветал» |
| Орган | атака 0.01, sustain 1, короткий release | модулятора нет |

### Шаг 5. Мелкие приёмы

- **Расстройка:** `Op 2 Frequency` = 1.01 при `Op 1` = 1 даёт хоровой эффект (StrPad).
- **Панорама:** `Pan 1` = −0.5 и `Pan 2` = 0.5 разводят две несущие по сторонам.
- **Микшер:** уровни `Mix` держите в сумме ≈1.5–2 для нескольких несущих, чтобы не клипировать.
- **Голоса:** `Voices` = 4 хватает для аккордов; для баса можно меньше.

## 3. Короткая схема по описанию звука

1. Звук должен быть **звенящим или металлическим** → нецелое ratio, алгоритм 1, IM 1.4–2.6, у несущей долгий спад.
2. Звук должен быть **тёплым и ударным** (бас, щипок) → целое ratio, алгоритм 1, IM 3–3.5, у модулятора короткий спад.
3. Звук должен быть **«клавишным»** → алгоритм 4, две пары, у второй короткий спад.
4. Звук должен быть **длинным и мягким** → алгоритм 2, медленные атаки, лёгкая расстройка, малый IM.
5. Звук должен быть **ровным, как орган** → алгоритм 6, IM = 0, несущие на 1, 2, 4.
6. После этого послушайте и поправьте **две ручки**: IM (яркость) и спад модулятора (как быстро яркость уходит). Это самый быстрый способ приблизиться к нужному звуку.

## 4. Что здесь не проверено

- Я не слушал рецепты сам, и их звучание не измерялось. Оценка «похоже на колокол» — это ожидание из теории, а не результат анализа записи.
- Соотношения вроде 7.13 и 3.5 взяты как типовые значения для стекла и колокола. Подбор «по вкусу» может дать лучший результат.
- В этом документе нет отдельной проверки поведения ручек BPM, Latch и Octave арпеджиатора на живом синтезаторе.
